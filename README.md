Lumen Tide — Keeper of the Last Light. A wave-based arena survival game in a night garden: guide the lantern spirit with WASD or arrow keys, gather drifting embers to build a combo, and pulse back the hunting shadow wisps with Space or a mouse click. Every third wave brings the Gloom Brute, a crowned shadow that takes three pulses to banish. Survive all 10 waves to bring the dawn — lose all three hearts and the light fades. Synthesised WebAudio sound, no audio files; all art is drawn live on canvas.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `node main.ts` (with `MAKEFUN_OUTPUT_DIR` set) hands the game in: it copies `game/` and `screenshots/` to the output directory and writes `dossier.json`.
